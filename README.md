# Clothespin for macOS

A screenshot, its source, and the context that matters.

Website: https://clothespin-mac.netlify.app

This repository hosts public release notes, downloadable installers, and feedback. The application source is maintained separately in a private repository.

Requires macOS 14 or later. Universal releases support Apple silicon and Intel; older macOS and Intel runtime testing is still needed during beta.

Captures remain local until you choose a destination. Claude and Muse support guarded draft preparation; other apps offer copy-and-open. Optional automatic Claude submission requires a separate opt-in.

Built on Tendedero by Alejandro Buján under its retained MIT license, with an independent Clothespin name and icon. See the license included in each installer.

Please report bugs in Issues without including private screenshots or credentials.
